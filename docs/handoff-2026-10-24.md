## 4. Important implementation details

- Fixtures are **function-scoped** now, not module-scoped. This was required
  because some modules mix portable tests with per-function `game(...)`
  markers (e.g. `test_review87`); a module-scoped `request.node` cannot see a
  function marker and would resolve the default Limbus fixture.
- `tests/conftest.py` caches only the loaded `Il2Cpp` object per
  `(metadata, binary)` in `_IL_CACHE`; each test gets a fresh
  `Decompiler(Lifter(il))`. Hashing is cached in `_SHA_CACHE`.
- `game_decompiler` is now the baseline-guarded alias. Use
  `raw_game_decompiler` only for metadata/layout invariants.
- `game_tree` requires `MANIFEST.json` and matching metadata/binary hashes.
- `game_support.find_method(il, type_name, name, params)` is the preferred
  lookup for focused tests; avoid adding new bare `mi` pins when type/name
  unambiguous.
- `--strict-games` fails only for games selected with `--game`; with no
  `--game` it applies to every game test.
